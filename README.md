# Viral Video Prompts

A browser-based prompt library from ReelBoop. Filter by shot type, review the suggested reference, then copy and adapt one of nine short-form video prompts.

- [Open the prompt picker](https://reelboop.github.io/viral-video-prompts/)
- [Read the original prompt library and case notes](https://github.com/creeep123/viral-video-prompts)
- [Try your own image in ReelBoop Photo to Video](https://reelboop.com/create/photo-to-video?utm_source=github&utm_medium=repository&utm_campaign=viral_video_prompts)

The site uses static HTML, CSS and JavaScript. The ReelBoop example footage is presented as a teaching reference. The Plus Jakarta Sans font license is in `assets/FONT-LICENSE.txt`.
